Sgt maintains its own wiki of its work, one per project, in Open
Knowledge Format (OKF) v0.2 — a root `index.md`, dated folders each with
their own `index.md`/`log.md`, and one concept page per completed run.
Content is a deterministic rendering of already-durable store facts
(brief, repos/bullets, outcome, PR links, blocked reason) — no LLM call,
no new data captured. Lives in its own folder under Sgt's own data root,
never the operator's personal `~/wiki`.
