## 2023-10-24 - SQLite IN Clause and Sorting Penalty
**Learning:** In SQLite, when querying with an `IN (...)` clause (e.g., `run_id IN (...)`), adding an `ORDER BY` clause will force a `TEMP B-TREE` sort even if there's an index on the queried columns (e.g., `(run_id, created_at)`). The index covers the data but cannot supply the requested sort order across the multiple discrete equality checks triggered by `IN`.
**Action:** When using `IN (...)` to bulk fetch IDs into a data structure (like a Go map or slice) where the processing order doesn't matter, explicitly remove the `ORDER BY` clause to avoid the in-memory sort penalty.
